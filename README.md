# Cheating Daddy

**AI-ассистент для технических разговоров и подготовки к собеседованиям.** Распознаёт вопросы из речи, помогает с кодом и схемами, учитывает ваш опыт. Новые ответы не мешают дочитать текущий.

## Главное

- **Управление разговором:** редактирование распознанных вопросов, темы и уточнения, пауза аудио с доступными текстовыми запросами.
- **Удобные ответы:** краткая суть и раскрываемые подробности, подсветка кода, таблицы, размер шрифта и свои кнопки быстрых запросов.
- **Preparation и AI Customization:** резюме, вакансия, истории проектов, редактируемые профили и дополнительные инструкции.
- **Скриншоты с заданием:** извлечение текста или анализ изображения целиком.
- **System Design:** единое окно с требованиями, схемой связей, решениями и откатом изменений. **Проверка кода:** запуск Go, Python и SQLite в Docker.
- **Во время звонка:** лента распознанной речи над ответом, телесуфлёр с автопрокруткой (Cmd/Ctrl+Alt+S), прозрачность окна горячими клавишами (Cmd/Ctrl+Alt+← / →), копирование кода и ответа одной кнопкой.
- **ИИ-итоги собеса:** после сессии модель собирает вопросы интервьюера, трудные темы и план, что подтянуть (History → Разбор).
- **Надёжность:** проверка готовности и скорости моделей, история сессий, повтор запросов и восстановление после перезапуска.

Основной режим — **OpenAI или OpenRouter**. Модели ответа, распознавания речи, текста на картинках и анализа изображений настраиваются отдельно. Gemini/Groq и Local AI используют прежний интерфейс с меньшим набором возможностей.

## Запуск

Нужны Node.js, npm и API-ключ выбранного провайдера.

```sh
npm install
npm start
```

1. На **Home** выберите провайдера, укажите ключ и модели.
2. В **Settings** настройте язык и источник звука; при необходимости выберите профиль и пакет подготовки.
3. Нажмите **«Проверить готовность»**, затем **Start Session**.

**Windows 10 (2004+) и 11:** системный звук захватывается автоматически, отдельной утилиты не нужно. Для микрофона включите доступ классическим приложениям в «Параметры → Конфиденциальность → Микрофон». Установщик `Setup.exe` собирается командой `npm run make` на Windows или скачивается из артефактов сборки GitHub Actions (вкладка Actions → Build → `cheating-daddy-windows`). Размер окна меняется уголком в правом нижнем углу.

На macOS разрешите запись экрана/системного звука и, если нужен, микрофон в **System Settings → Privacy & Security**. После изменения разрешений перезапустите приложение. Для показа окна другу включите **Settings → Appearance → «Показывать окно при демонстрации экрана»**.

Проверка скорости использует инструкции сессии: текст проверяет модель ответа, голос добавляет распознавание речи, изображения — обработку картинок. Запросы оплачиваются через API провайдера.

## Данные и разработка

Ключи, настройки и история хранятся локально вне репозитория; ключи — в незашифрованном `credentials.json`. Каталог: macOS — `~/Library/Application Support/cheating-daddy-config`, Windows — `%APPDATA%\cheating-daddy-config`. В облачных режимах запросы и нужный контекст отправляются выбранному провайдеру.

```sh
npm test         # тесты
npm run package  # приложение в out/
npm run make     # установочные артефакты
```

Стек: Electron, JavaScript, Lit. Для запуска кода нужен Docker.
