# Claude Code и ChatGPT

На главной выберите «Claude Code» или «ChatGPT · Codex». Приложение запускает установленный CLI с его текущей авторизацией. Пароли и токены входа в интерфейс приложения вводить не нужно.

- Для Claude Code выполните в терминале `claude auth login`.
- Для ChatGPT выполните `codex login` и выберите вход через ChatGPT. Приложение также ищет CLI, поставляемый с установленным ChatGPT для macOS.
- Нажмите «Проверить подключение»: это короткий реальный запрос к выбранному провайдеру.

Мост отвечает на текстовые запросы. В настройках подключения можно отдельно включить OpenAI / OpenRouter для распознавания речи и изображений — для этого нужен API-ключ, расходы идут отдельно от подписки. Режим «Без аудио и изображений» позволяет работать только с текстом без такого ключа.

CLI запускается во временном пустом каталоге, без инструментов и настроек проекта. В запрос передаются история разговора и выбранный контекст подготовки. При выходе из приложения незавершённые процессы моста останавливаются.

Резюме и вакансии хранятся отдельно в «Настройках AI». При сохранении старой библиотеки она преобразуется в новый формат; исходный файл сохраняется рядом как `interview-workspace.json.v1-backup`.

Официальные инструкции: [авторизация Codex](https://developers.openai.com/codex/auth), [неинтерактивный Codex](https://developers.openai.com/codex/noninteractive), [Claude Code CLI](https://code.claude.com/docs/en/cli-reference).
