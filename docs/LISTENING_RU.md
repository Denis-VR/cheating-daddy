# Прослушивание собеседника

В сессиях OpenAI и OpenRouter выберите в Settings источник «Системный звук» или «Оба». Собеседник должен звучать через компьютер. Микрофон показывается отдельно в ленте речи и не создаёт черновики вопросов.

«Реплики собеседника» — распознанная речь, а не вопросы, придуманные AI. Близкие фрагменты объединяются. Распознавание может ошибаться; проверяйте текст.

По умолчанию включён ручной режим: выберите реплику, исправьте текст и нажмите «Ответить». Ненужную реплику можно удалить. Формат ответа и тема выбираются в панели инструментов. Переключатель автоответов расположен в верхней строке рядом со статусом и паузой; он доступен и при скрытых панелях.

Кнопка «Автоответы: выкл» включает ответы на новые явные вопросы и задания. Через 5,5 секунды без дополнений приложение отправляет подходящую реплику в AI. Определение вопроса использует простые признаки русского/английского текста; неявные вопросы могут остаться для ручного выбора. Уже собранные черновики и реплики, которые вы редактировали, автоматически не отправляются. Переключатель действует в текущей сессии.

Выключение автоответов отменяет ожидающую отправку; уже начатый ответ завершится. «Пауза» останавливает обработку разговора и ожидающие автоответы, но позволяет писать запросы вручную. При возобновлении ожидающие новые вопросы снова доступны для автоматической обработки. При ошибке автоответы выключаются, запрос можно повторить вручную.

Новые ответы не переключают текущую тему: откройте их через список тем или навигацию ответов. Транскрипция и ответы в этих режимах обрабатываются выбранным API провайдером и расходуют его оплачиваемый лимит.

Запуск из корня проекта: `npm start`. Проверка поведения очереди и обработки звука: `npm test`.

Источник «Звук компьютера — звонки, видео, голосовые» захватывает звук приложений Mac, включая браузер и проигрыватель. «Звук компьютера + микрофон» добавляет микрофон отдельным каналом. При смене источника лента речи включается; её можно скрыть кнопкой «Речь» рядом с суфлёром. Ошибка доступа к выбранному микрофону останавливает запуск с объяснением. Для macOS нужны разрешения на микрофон и запись экрана / системного аудио.

«Реплики», «Темы», инструменты и режим ответа находятся в верхней панели. Резюме и вакансии редактируются в «Настройках AI»; в инструментах сессии остаются проверка кода и проектирование.
